# CLAUDE.MD

## Project Overview

This is **ai_playground** - a repository for experimenting with AI development, testing AI-assisted coding workflows, and exploring various AI tools and frameworks.

## Purpose

This repository serves as a sandbox environment for:
- Testing AI code generation capabilities
- Experimenting with different AI models and frameworks
- Prototyping AI-powered applications
- Learning and documenting AI development patterns
- Exploring prompt engineering techniques

> **💡 For detailed information**: Check the `docs/` directory, especially `docs/CONTEXT.md` for comprehensive project context and conventions.

## Development Guidelines

### Code Style
- Write clean, readable, and well-documented code
- Use meaningful variable and function names
- Include comments for complex logic
- Follow language-specific best practices

### Git Workflow
- Work on feature branches following the pattern: `claude/feature-name-{sessionId}`
- Write clear, descriptive commit messages
- Keep commits focused and atomic
- Push changes to the designated branch

### Testing Philosophy
- Write tests for critical functionality
- Include examples and usage documentation
- Test edge cases and error handling
